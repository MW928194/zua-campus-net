# 杀毒软件报毒（火绒 / Windows Defender）说明

> 不少同学第一次运行时会被火绒（Huorong）或 Windows Defender 拦截甚至删除文件。
> **这是"行为敏感"导致的误报，不代表文件真的有恶意代码**。本文说明原因、如何确认安全、如何处理，以及如何帮我们提交误报。

## 一、为什么会被报毒

本工具确实会做这些"敏感动作"：

| 动作 | 为什么需要 | 为什么会被拦 |
|---|---|---|
| 注册 **SYSTEM 权限的开机计划任务** | 开机时在锁屏界面就完成登录 | "开机自启 + 高权限持久化"是木马/后门的典型行为 |
| 用**隐藏窗口**运行 PowerShell | 后台守护不打扰用户 | "隐藏运行脚本"是常见恶意特征 |
| 申请管理员权限（UAC） | 注册系统级计划任务 | 提权 + 持久化组合会被重点监控 |
| 在本机保存账号密码 | 自动登录需要 | "脚本保存凭据"容易被判为窃密行为 |
| 结束旧的守护进程 | 更新/重装时避免重复实例 | "结束进程"也是敏感行为 |

这些特征与恶意软件的持久化手段高度重合，所以启发式/行为引擎会直接拦截。**本项目全部代码开源，可以逐行核对。**

## 二、怎么确认它是安全的

1. **源码**：<https://github.com/MW928194/zua-campus-net>
2. **网络请求只有两类**：
   - 学校认证门户 `202.196.169.166`（登录/查状态）；
   - 网络连通性检测：`www.msftconnecttest.com`、`connect.rom.miui.com`（系统自带网络探测也会用）。
   不向任何第三方上传数据，没有下载执行、没有外联服务器。
3. **凭据只在本机**：`C:\CampusNet\cred.dat`，用 Windows DPAPI 加密，只有本机可解密。
4. 它不读取浏览器密码库、不抓取其他账号、不修改系统设置（除了注册它自己的计划任务）。

## 三、火绒（Huorong）被删 / 被拦怎么办

界面文案可能因版本略有差异，核心是「**先恢复 → 再加信任 → 再运行**」。

1. **恢复被隔离的文件**：
   打开火绒 → **病毒查杀** → **隔离区** → 勾选被隔离的文件 → 点 **恢复**。
   （如果文件是被直接删除、不在隔离区：先按第 2 步把**解压目录**加入信任，再重新解压一遍。）
2. **添加信任**：
   火绒 → **病毒查杀** → **信任区**（部分版本在右上角 **菜单 → 信任区**）→ **添加文件夹** →
   选择解压出来的整个 `zua-campus-net` 文件夹。
3. 重新双击 `启动.bat`。

> 建议只添加"信任文件夹"，**不要关闭火绒的整体防护**。

## 四、Windows Defender / SmartScreen

- 解压被拦：**Windows 安全中心 → 病毒和威胁防护 → 保护历史记录** → 对相关项选择 **允许/还原**；
- 运行被拦：点"更多信息 → 仍要运行"；
- 或：**病毒和威胁防护 → 管理设置 → 排除项 → 添加排除项 → 文件夹**，选择解压目录。
- 从浏览器下载的 zip 可能带"来自网络"标记，可右键 zip → 属性 → 勾选"解除锁定"再解压。

## 五、帮我们解除误报（推荐）

火绒官方明确表示**没有"软件白名单报备"机制**，但确认是误报后会解除查杀。可以这样反馈：

- 火绒论坛「病毒反馈」版块：<https://bbs.huorong.cn/forum-44-1.html>
- 火绒官方邮箱：`service@huorong.cn`
- 火绒官方客服：`400-998-3555`（或火绒论坛发帖）

**提交时需要**（按火绒官方要求）：把**被误报的样本文件从隔离区提取**，并**导出对应的查杀安全日志**，一起上传。

可以直接复制下面的模板：

```text
【误报反馈】开源的校园网自动登录工具被报警

下载/源码地址：https://github.com/MW928194/zua-campus-net
被报毒文件：<火绒提示的文件名，例如 启动.bat / CampusNet-GUI.ps1>
火绒提示的病毒名称：<火绒弹窗里的名称，最好附截图>
火绒版本 / 病毒库版本：<设置-关于 里查看>
系统版本：<Windows 11 23H2 等>

说明：这是开源的高校校园网自动登录工具（PowerShell + WinForms），
行为是注册本机计划任务、在后台上报校园网门户认证状态，不联网上传数据，
不含恶意代码，源码可公开核对。请帮忙复核并解除误报。
样本与查杀日志见附件。
```

## 六、如果还是不想加信任

- 可以只用 GitHub 上的源码手动运行（仍需执行 PowerShell 脚本）；
- 或者干脆不使用本工具——**不要为了运行它而关闭杀毒软件的整体防护**。
