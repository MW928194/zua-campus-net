# 郑航校园网自动登录（ZUA-Student Auto Login）

> 一个给郑航同学用的小工具：**开机 / 锁屏界面就自动完成校园网网页认证，掉线自动重连**。
> 不用打开浏览器，不用每天点登录；密码加密保存在本机。

- 适用网络：郑州航空工业管理学院 `ZUA-Student`（网页认证，`bossWeb` 门户）
- 适用系统：Windows 10 / 11（只依赖系统自带 PowerShell 5.1 + .NET Framework，无需安装任何东西）
- 界面：一个简单窗口 —— 输入学号密码 → 点一下安装，完事

## 功能

| 功能 | 说明 |
|---|---|
| 开机自动登录 | 注册 SYSTEM 计划任务，开机即以系统身份运行，**锁屏、解锁之前**就开始认证 |
| 掉线自动重连 | 常驻守护进程每 6 秒检查一次认证状态，掉线自动重新登录（全天有效） |
| 图形界面 | 安装 / 更新凭据 / 暂停 / 恢复 / 卸载 / 自检 / 断网测试，全部点按钮 |
| 密码安全 | Windows DPAPI（机器级）加密保存在本机 `C:\CampusNet\cred.dat`；不联网上传、不读取浏览器密码 |
| 安装时校验 | 输入密码后先向学校服务器真实验证，密码错了当场提示，不会装完了才发现 |
| 零依赖开源 | 纯 PowerShell 脚本，全部代码可见、可改 |

## 使用方法

1. **先连上 `ZUA-Student` 校园网**（已保存过这个 Wi-Fi 即可）。
2. 解压后双击 **`启动.bat`**（会弹 UAC，点“是”）。
3. 在窗口里输入：
   - **学号**（校园网登录账号）
   - **校园网密码**（默认是身份证后六位；不确定可以到 Edge「设置 → 个人资料 → 密码」里查看保存的密码后复制）
4. 点 **“一键安装 / 更新凭据”**，看到“安装成功”即可。
5. （可选）点 **“真实断网测试”** 验证一次：它会主动下线再自动登录，期间断网约 10~30 秒。

之后就不用管了：开机自动登录、掉线自动重连。

## 验证“真的在解锁前登录了吗”

重启电脑 → **停在锁屏界面别输密码** → 等 1~2 分钟 → 再解锁登录，然后打开
`C:\CampusNet\login.log`（界面里点“打开日志”）。日志里应该有一条
**时间早于你解锁时间** 的 `登录成功`。

> 注意：开机自动登录能否赶在解锁之前，取决于电脑开机速度；脚本会在开机后尽早运行。
> 即使偶尔慢几秒，解锁后也会很快自动联网。

## 界面说明

- **运行状态**：计划任务状态 / 守护进程 / 当前网络 / 最近一条日志
- **账号与安装**：输入学号密码；“一键安装 / 更新凭据”用于首次安装和改密码
- **测试与维护**
  - `快速自检`：只读检查配置、网络、认证状态（不登录、不断网）
  - `真实断网测试`：暂停守护 → 主动下线 → 自动登录 → 恢复（会短暂断网）
  - `暂停自动登录` / `恢复自动登录`：临时停用（重启后自动恢复）
  - `卸载`：删除计划任务、守护进程和 `C:\CampusNet`
  - `打开日志`：查看运行日志

## 常见问题（FAQ）

**Q：提示“密码错误”？**
A：密码输错了或学校改过密码。到 Edge「设置 → 个人资料 → 密码」里搜 `202.196.169.166` 查看保存的密码，
复制粘贴到安装窗口；也可以先到认证页自助重置/修改密码后再安装。

**Q：开机后没有自动登录？**
A：先点“打开日志”看最后几行：
- 出现 `密码错误` → 重新安装更新密码；
- 一直是 `认证服务器不可达` / `Wi-Fi 未连接` → 锁屏界面 Wi-Fi 还没连上，属个别机器/驱动问题，可反馈日志；
- 出现 `登录成功` 但时间晚于解锁 → 只是开机慢了一点，网络随后会自动恢复。

应急方案：用 Edge 手动点两下登录（自动填充还留着）。

**Q：杀毒软件/Windows 提示风险？**
A：本项目是明文 PowerShell 脚本，安装的是 SYSTEM 计划任务与自启动脚本，部分安全软件会提示。
请先阅读源码确认；被拦截时选择“允许/信任”。

**Q：如何卸载？**
A：打开本工具点“卸载”；或删除计划任务 `CampusNet-AutoLogin` 后删除 `C:\CampusNet`。

**Q：换电脑 / 换账号？**
A：在新电脑上重新运行 `启动.bat` 安装即可；换账号重新安装（会覆盖旧凭据）。

**Q：我想自己改，或用于其他学校？**
A：见 [docs/how-it-works.md](docs/how-it-works.md)，把 `config.json` 里的门户地址/参数改成你们学校的即可。

## 工作原理（简述）

学校门户（`bossWebV1.0.1`）的流程：

1. 连上 `ZUA-Student` 后，网关把所有 HTTP 请求 302 重定向到认证页
   `http://202.196.169.166/webauth.do?wlanacip=...&wlanacname=...&wlanuserip=...&mac=...`
2. 认证页是一个表单，提交 `userId` + `passwd` 到 `/webauth.do` 即完成登录。
3. 认证状态可通过 `GET /webdisconnweb.do?wlanacname=ZZHK-ZAX-BRAS` 判断（302 到 `act=LOGINSUCC` 即在线）。

本工具不启动浏览器，而是：

- 以 **SYSTEM 计划任务** 在开机时启动守护脚本（所以早于用户登录）；
- 守护脚本用门户状态接口判断是否在线；
- 未认证时自动发现登录页、解析全部表单字段、填入账号密码并重放 POST；
- 认证成功后每 6 秒复查一次，掉线自动重登。

详见 [docs/how-it-works.md](docs/how-it-works.md)。

## 安全与隐私

- 密码使用 Windows DPAPI **机器级** 加密保存，只有本机（含 SYSTEM）能解密；脚本与仓库中不含任何明文凭据。
- 本工具**不收集、不上传**任何数据；唯一网络请求是学校认证服务器和网络连通性探测。
- 因为密码可被本机任意用户解密，**建议只在个人电脑上使用**。
- 请只登录自己的账号；学校规定一人一号、禁止转借共享。
